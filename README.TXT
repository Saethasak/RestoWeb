RestoWeb
------------------------------------------------------------------------
Created by Tyron, Thomas and Vicky
------------------------------------------------------------------------
RestoWeb is a virtual recipe book that allows you to look at and add recipes. 
It also allows you to see and write your own review along with a rating.
You may find recipes based on the category, tag or name.
------------------------------------------------------------------------
Date of creation: November 23rd, 2026
------------------------------------------------------------------------
To start this project, you must checkout the project by copying the repository link and clicking "Checkout project" under team on BlueJ.
